# AI 안심 냉장고 & 스마트 식재료 매니저 — GitHub Pages 버전

## 배포 방법
1. GitHub에서 새 **Public** 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 **Save**를 누릅니다.
6. 잠시 기다리면 `https://깃허브아이디.github.io/저장소이름/` 주소로 접속할 수 있습니다.

## 기능 및 구현 범위
- 원본의 5개 탭 구성과 한국어 UI를 브라우저용으로 재구현했습니다.
- 식재료 이미지: 브라우저 Canvas에서 밝기·채도·밝기 편차를 계산해 신선도 점수를 참고용으로 추정합니다. 원본 Python의 컴퓨터 비전 분석식을 JavaScript로 옮긴 것이며, 학습된 식품 분류 AI가 아닙니다. 평균 RGB 기반 식품 종류 추정도 제한적입니다.
- 영수증: 텍스트 직접 입력, 날짜·품목 추출, 개인정보 마스킹, 가공식품 소비기한 입력을 지원합니다. 사진은 미리보기이며 OCR은 수행하지 않습니다.
- 냉장고: 추가·삭제·소비 우선순위 계산을 지원합니다. 데이터는 현재 브라우저의 localStorage에 저장되므로 다른 기기와 자동 동기화되지 않습니다.
- 레시피: 원본 Python 모듈의 기본 레시피 8종, 알레르기 및 문화/종교 식단 필터링, 재료 매칭 점수 계산을 브라우저에서 구현했습니다.
- 책임 있는 AI 보고서 탭에 구현 범위와 한계를 명시했습니다.

## 주의
- GitHub Pages는 정적 호스팅이므로 Python/Streamlit 서버를 실행하지 않습니다.
- 신선도 점수는 참고용이며 실제 식품 안전성을 보장하지 않습니다.
- 개인정보가 포함된 실제 영수증을 외부에 공개하지 마세요.
